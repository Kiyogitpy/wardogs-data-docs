The Range Finder is a recon optic with high, variable magnification. Its main difference from the [Monocular](monocular.md) is the accurate distance indicator. The [Infrared Range Finder](infrared-range-finder.md) is the more expensive version of the same idea.

## Overview

The shop text lists the Range Finder as a high magnification optic with an accurate distance indicator. The data gives no spotting range, so the distance the optic reads out at long range is not yet known.

## How it works

- It is used by aiming, with the item's secondary input.
- While it is in use, maximum movement speed is halved.
- The item data gives the Range Finder no reload action. Only the Infrared Range Finder has one.
