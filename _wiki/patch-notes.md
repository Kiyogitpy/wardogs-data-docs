# Patch Notes

Patch notes summarise what changed between one season of Wardogs and the next. Each summary is written from the Season 1 and Season 2 game data, groups the changes by area, and keeps only the changes that affect play. For every changed value, the full list is on the Season 2 Changes pages of the data reference.
