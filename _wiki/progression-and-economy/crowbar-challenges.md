# Crowbar Challenges

| Crowbar Challenges | |
|---|---|
| **General** | |
| Kind | Event reward |
| Challenges | 1 |
| Auto-activate | Yes |
| Internal name | DT_Challenges_SessionEvents_Crowbar |
{: .wiki-infobox }

The crowbar challenge pays when a player forces a door open. The crowbar is the [Halligan Bar](../equipment/halligan-bar.md).

## Challenges

| Challenge | What earns it | Cash (base) | Role XP (base) |
|---|---|---|---|
| Door Forced Open | Breaching a door | Base 0.5, owner assist 0.25 | Base 0.25, owner assist 0.1 |

The sources give the base numbers but not the formula that combines them with the event, so they are shown as the data lists them.

## Season 2 changes

The sources list no Season 2 changes for this challenge.
