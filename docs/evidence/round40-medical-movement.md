# Round 40: Medical, armour and movement gaps (continuation of round 39)

GitHub-only evidence page (docs/ is not on the site). Closes the 23 NOT SEARCHED and 3 NATIVE-partial items of [round 39](round39-medical-movement.md). Every item had its own time box.
Statuses: FOUND, NATIVE (open, with the exact next step), ABSENT (searched, not present), PROTECTED, SERVER. No item is left "not searched".
Evidence levels: **cooked data read** (data/ JSON or `WdExtract dump`), **bytecode read** (Kismet from `WdExtract dump`, `decode.py`), **static disassembly / decompile** (restored exe, corpus `decompiled_cl516586_20261017_mmvpuc__`, image base 0x140000000, RVAs below), **Derived**. The game was not run; no devirtualization; the protected layer was not touched (no item sat behind it).

Method notes. `WdExtract` (round36_ai/bin) `list ""` for the package list, `findname Wardogs <name>` (FName search: it proves "no asset names this", not "no asset sets this unversioned property"), `dump` for the Blueprints and data assets. Native readings use the corpus `functions` table, vtable-slot aliases (`UBHMoverMode_GroundMovement_VFT::slot_N`) and byte scans for displacement loads. Generated data: `python -I _tools/round40_medical_movement.py --write` writes `assets/data/medical-status-r40.json`, section 11 of the Medical page and section 7b of the Player Movement page. Scratch: `round40_med/`.
