## Wiki updates

- `_wiki/game-mechanics/ballistics.md` (effective range): "only consumer found is the wind ramp" -> confirmed. The wind begins to push the bullet once it has travelled the effective range (x100 cm, x1.2 armor piercing, x0.8 hollow point) and is at full strength from about 1.41 times that distance; nothing else (damage, spread, despawn) reads it.
- `_wiki/game-mechanics/penetration-and-ricochet.md`: the "how the game uses the 0.8 and 1.2 multipliers" gap is closed (they only shift the wind onset distance; exit speed is separate); remove the entry from the "not yet known" list.
- `_wiki/game-mechanics/movement.md`: "crouch and prone deceleration unknown" -> there is none; stopping friction (6.0) is the same in every stance, only acceleration (7 / 12 / 19) and max speed differ. "Slope speed curve input units unknown" -> slope angle in degrees weighted by a direction factor.
- `_wiki/equipment/parachutes.md`: "damage curve values not in the data" -> 695 cm/s and below = 0 damage, rising linearly to 100 damage at 1,700 cm/s.
- The revive or medical page that lists `BleedOutRevivePenaltyOffset` 100: add that no code that reads it was found, so it has no known effect.
- The inventory or magazine page: "tracer rounds without the ammo tag" -> the load rule checks only the magazine tag, the magazine's caliber filter and free capacity.
- The 155 mm artillery page: the guided 155 mm shell steers sideways only, input scaled by 0.02 per tick and averaged over the tick; no vertical steering.
- The character modifier or camera page: when several modifier states have the same priority, their order is not defined (unstable sort).
