# Wardogs: Experience Configs (rule variants, match-state ini, example server)

*Source: [`Config/Experiences/`](https://github.com/Kiyogitpy/wardogs-data-docs/tree/main/data/Wardogs/Config/Experiences) (34 JSON files), `DefaultMatchState.ini` and `ServerConfigs/ExampleStandaloneServerConfig.ini`. The tables are generated by `_tools/experience_config_tables.py` (`--check` to verify). The example server file also holds an admin password field and a banner URL; neither is copied here. The cooked experience packs themselves are in [Experiences (feature)](Wardogs_GameFeatures_Experiences_v2.md); the config values that override native defaults are in the Default Game ini data (`assets/data/default-game-ini.json`).*

An **experience** is a small config file that names a mode: which game feature packs it turns on, which rule flags it sets, which data layers (map content) it loads. `Includes` stacks one definition on another, so [`Bakurani_KOTH_01`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Config/Experiences/Kavkazi/Bakurani_KOTH_01.json) is `KOTH` plus the Bakurani map layers.

## 3. Hardcore and Infantry Only

These two are the KOTH variants that the server browser tags as **Hardcore** and **Infantry Only** (see the tag rows in [Frontend data tables](../content/Wardogs_DataTables_Frontend_v1.md) and [Tag Display Text](../content/Wardogs_TagDisplayText_v1.md)).

**Hardcore** ([`KOTH_Hardcore`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Config/Experiences/KOTH_Hardcore.json), alias `Hardcore`) turns off these parts of the screen and feedback:

- Rule flags set: `NoDynamicCrosshair`, `KillfeedSquadOnly`, `NoHudAmmo`, `NoMinimapHealth`, `NoQuickSlots` and `Hardcore`.
- Game feature packs disabled: [`AlternativeCriticalCamera`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Plugins/GameFeatures/AlternativeCriticalCamera/Content/AlternativeCriticalCamera.json) and [`PlayerHealthBar`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Plugins/GameFeatures/PlayerHealthBar/Content/PlayerHealthBar.json).
- Feature flag disallowed: `Vehicle.Feature.ThirdPersonCamera`.
- The file has no `Includes` line, so it is a rule layer meant to sit on top of a KOTH definition; how the layer is attached is not in the file.

**Infantry Only** ([`KOTH_InfantryOnly`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Config/Experiences/KOTH_InfantryOnly.json), alias `InfantryOnly`) includes `KOTH`, sets the rule flag `InfantryOnly` and disables 13 vehicle and emplacement packs:
