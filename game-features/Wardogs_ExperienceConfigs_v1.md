# Wardogs: Experience Configs (rule variants, match-state ini, example server)

*Source: [`Config/Experiences/`](https://github.com/Kiyogitpy/wardogs-data-docs/tree/main/data/Wardogs/Config/Experiences), `DefaultMatchState.ini` and `ServerConfigs/ExampleStandaloneServerConfig.ini`. The tables are generated by `_tools/experience_config_tables.py` (`--check` to verify). The example server file also holds an admin password field and a banner URL; neither is copied here. The cooked experience packs themselves are in [Experiences (feature)](Wardogs_GameFeatures_Experiences_v2.md); the config values that override native defaults are in the Default Game ini data (`assets/data/default-game-ini.json`).*

The CL533731 hotfix candidate contains four standalone definitions in this curated export, compared with 34 in the saved baseline. `KOTH_InfantryOnly` is absent here, so its historical disabled-feature list is not presented as current configuration. Absence from these files does not establish mode removal or resolve includes supplied elsewhere. See [hotfix evidence and limits](../docs/evidence/hotfix-cl533731.md).

Citations pinned to a full Git revision retain historical CL516586 source files. The current generated tables and historical mode descriptions have different evidence scopes.

An **experience** is a small config file that names a mode: which game feature packs it turns on, which rule flags it sets, which data layers (map content) it loads. `Includes` stacks one definition on another, so [`Bakurani_KOTH_01`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/8d0d6a9a0a3a0a0170e7ff3929202a92a5b9c12b/data/Wardogs/Config/Experiences/Kavkazi/Bakurani_KOTH_01.json) is [`KOTH`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Plugins/GameFeatures/Experiences/KOTH/Content/KOTH.json) plus the Bakurani map layers.

## 3. Historical Season 2 Hardcore and Infantry Only

These two are the KOTH variants that the server browser tags as **Hardcore** and **Infantry Only** (see the tag rows in [Frontend data tables](../content/Wardogs_DataTables_Frontend_v1.md) and [Tag Display Text](../content/Wardogs_TagDisplayText_v1.md)).

**Hardcore** ([`KOTH_Hardcore`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/8d0d6a9a0a3a0a0170e7ff3929202a92a5b9c12b/data/Wardogs/Config/Experiences/KOTH_Hardcore.json), alias `Hardcore`) turns off these parts of the screen and feedback:

- Rule flags set: `NoDynamicCrosshair`, `KillfeedSquadOnly`, `NoHudAmmo`, `NoMinimapHealth`, `NoQuickSlots` and `Hardcore`.
- Game feature packs disabled: [`AlternativeCriticalCamera`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Plugins/GameFeatures/AlternativeCriticalCamera/Content/AlternativeCriticalCamera.json) and [`PlayerHealthBar`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Plugins/GameFeatures/PlayerHealthBar/Content/PlayerHealthBar.json).
- Feature flag disallowed: `Vehicle.Feature.ThirdPersonCamera`.
- The file has no `Includes` line, so it is a rule layer meant to sit on top of a KOTH definition; how the layer is attached is not in the file.

**Infantry Only** ([`KOTH_InfantryOnly`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/8d0d6a9a0a3a0a0170e7ff3929202a92a5b9c12b/data/Wardogs/Config/Experiences/KOTH_InfantryOnly.json), alias `InfantryOnly`) includes [`KOTH`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/data/Wardogs/Plugins/GameFeatures/Experiences/KOTH/Content/KOTH.json), sets the rule flag `InfantryOnly` and disables 13 vehicle and emplacement packs:

## 5. Legacy match-state ini

`DefaultMatchState.ini` names three match-state classes that are not in the current SDK; the states in use are the `MatchState.*` sections of the Default Game ini data (post-match 45 s there against 35 s here). The numbers are real file content, but their consumer is not shown, so treat them as legacy.

In words: the waiting state lasts 5 s and blocks purchases, vehicle spawns, stat tracking and cash earning; the in-progress state has no limit; the ending state lasts 35 s; everything else defaults to purchases, vehicle spawns, stats and cash on.
