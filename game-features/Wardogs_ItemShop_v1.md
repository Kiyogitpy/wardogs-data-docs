# Wardogs: Item Shop for Non-Weapon Items

Shop and item data for everything that is not a weapon, a weapon part or ammo: armor, helmets, vests, backpacks, parachutes, medical items, throwables, mines and explosives, tools, the bow, supply crates, vehicle items and vehicles. The tables are generated by `_tools/item_shop_tables.py` (`--write`). Weapons and weapon parts are in [Weapon Shop](Wardogs_WeaponShop_v1.md); ammo is in [Items](../content/Wardogs_Items_v2.md) (resource and ammo table); structures are in [Buildables](Wardogs_Buildables_v1.md). Hand-written price notes for these items are in [Items (feature)](Wardogs_GameFeatures_Items_v2.md), [Game Mechanics](../content/Wardogs_GameMechanics_v2.md) (vendor tables) and [Vehicles](Wardogs_GameFeatures_Vehicles_v2.md) section 3.

## Sources and labels

| Label | Source |
|---|---|
| **Data** | `WDVendorData` tables (`DT_VendorData_*`, `DT_GearMarket`, `DT_UtilityMarket`, `DT_VehicleMarket_*`, `DT_GarageMarket_SupplyCrates`): price, unlock level, required items, lifetime buy limit, amount, variations, categories. |
| **Data** | `BHEntityData_UI` tables (`DT_EntityData_*`): display name, subtitle, description, category tag. When a name or description is empty in the export, the table shows the string-table key as `[key ...]`. |
| **Data** | `ID_*` item definitions (`BHInventoryItemDefinition` plus the fragments in the same file): weight, inventory size, stack size, armor stages, durability, quick slots, backpack grids, heal values, throw velocity, placement limits. |
| **Derived** | Grouping into sections (by item id), and which table a row comes from (the entity row whose key equals the vendor row key, case ignored; the table in the same plugin folder is listed first). |
| **Native** | none used. Damage and armor rules are in [Damage Pipeline](../pipelines/Wardogs_DamagePipeline_v2.md); this page lists only the item values the rules read. |

The vendor rows hold no currency field. "Price" is the `Price` of the first variation with `bShowInVendor = true`, else of the first variation; "(hidden)" means no variation is shown in the vendor. "Variations" is how many variations the row has (every row here has one). "Amount" is the stack bought in one purchase. "Buy limit" is `LifeTimeBuyLimit` (`-` when 0). Armor "reduction %" and "density" are the four `DurabilityStagesSetupData` stages in order; how a stage is chosen from current durability is in the Damage Pipeline page. Weights and sizes are as exported; their units are not decoded.

## 9. Open items

- Heal rates, explosion damage and radius, and the vehicle statistics are not on the item definitions. They sit in action data, gameplay effects, thrown or placed actors and vehicle stats assets, and are not decoded on this page.
- "Weight" and "inventory size" are exported values; units and the way the inventory grid uses them are not traced.
- `bShowInVendor = false` rows are listed with "(hidden)"; whether a hidden row can be bought some other way is not traced.
