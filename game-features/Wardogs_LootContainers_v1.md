# Wardogs: Loot Containers

Loot containers are the world pickups placed by map markers (the Lootable world feature). A marker actor carries a tag that names a row of `DT_LootableDataTable`; the row says which item can appear there, with what chance, and how it respawns. This page lists all 52 rows of the table plus the 2 rows of the VIP Escort scenario table. The tables below are generated by `_tools/loot_tables.py` from the exported data (also written to [loot-tables.json](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/assets/data/loot-tables.json)). Which markers exist on which map is on [WorldFeatures](Wardogs_GameFeatures_WorldFeatures_v2.md) and the PvE pages.

## Sources and labels

| Label | Meaning |
|---|---|
| **Data** | A value read from the exported table `DT_LootableDataTable` or `DT_LootableDataTable_VIPEscort_01`. |
| **Native** | A rule read from the game code (static disassembly, [round 59 evidence](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/docs/evidence/round59-open-questions.md), section 4). |
| **Derived** | Computed here: the chance per draw is the entry weight divided by the sum of the weights of the row. |

## 1. How a container picks its item

1. **Which row.** At match start the server reads the marker's tags and keeps the one that matches a row name (Native). Rows with "Control zone only" set (`Lootable.Tower`, `Lootable.AbandonedTower`) wait for the control-zone state; every other row spawns at once (Native).
2. **Spawn roll.** The row's `SpawnChance` is turned into a roll of 1 in N with N = (200 / chance + 0.5) rounded down, then halved and rounded down. 100 always passes, 50 is 1 in 2, 25 is 1 in 4, 20 is 1 in 5 (Native). If the roll fails and the row can respawn, a timer of `RespawnTime` seconds starts and the roll repeats.
3. **Item draw.** The weights of all entries are added up (leaving out the entry chosen last when "never repeats" is on), a random point in that sum is drawn, and the entry whose running total reaches it wins (Native). The chance per draw is therefore weight / sum (Derived). With "never repeats" on, the previous item is removed from the next draw, so the other entries become more likely right after it.
4. **Sub-items.** The sub-items of the chosen entry (a magazine, a scope, ammunition, grenades) are spawned on the ground next to the main item, 40 to 180 cm away at a random angle (Native). Most sub-items have a 100% chance and always come with the main item; the few with a lower chance (for example the Bandage on some sniper rows, 25%) show it in brackets.
5. **Not read.** `bSpawnByPoints` and `InitialSpawnPoints` have no reader in the component code that was traced; their meaning is not known. They are shown as exported.
