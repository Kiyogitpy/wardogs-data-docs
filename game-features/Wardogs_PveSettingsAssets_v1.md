Every table below is generated by [`_tools/pve_settings_tables.py`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/_tools/pve_settings_tables.py); do not edit it by hand.*

This page lists, with values, every asset in those folders whose name appears on no other published page (the generator re-checks that on every run, so an asset documented elsewhere later drops off here). Related pages: [PvE feature](Wardogs_GameFeatures_PvE_v2.md) for the scenario packs.

## How to read a row

- Each row flattens the asset's `Properties` to `path=value`. Tags show as the tag name, object references as the referenced asset name. Null and empty values are dropped. A long row is cut with `(+N more values)`; the file under the Asset link has everything.
- Property names beginning `_aaab...` are obfuscated names the export could not resolve; they are shown as stored, with no meaning claimed.
- Animation sets are large; they show only the top-level properties with their leaf-value counts.
- What an asset type is for is **inference** from the engine class name and property names; the export stores no documentation.
- Left out on purpose: audio (`WDAudioData` files and `AEB_*` audio event behaviours in the same folders; voice-over rows show only the audio event tag name as stored) and UI widgets. This page documents no audio or UI widget assets.
