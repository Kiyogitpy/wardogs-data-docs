# Wardogs: Vehicle Assets (per-vehicle plugin data assets)

*Source: the export files under [`data/Wardogs/Plugins/GameFeatures/Vehicles`](https://github.com/Kiyogitpy/wardogs-data-docs/tree/main/data/Wardogs/Plugins/GameFeatures/Vehicles) (`TNK_01`, `ROT_02`..`ROT_04`, `SPW_01`, `STN_01`..`STN_03`, `WHL_01`..`WHL_07` and their weapon-variant folders, `SupplyCrates`). Every table below is generated by [`_tools/vehicle_asset_tables.py`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/_tools/vehicle_asset_tables.py); do not edit it by hand.*

This page closes the gap left by the other vehicle pages: it lists, with values, every vehicle-folder asset whose name appears on no other published page (the generator re-checks that on every run, so an asset documented elsewhere later drops off here). Pages that already carry the main per-vehicle numbers: [Vehicle Handling](Wardogs_VehicleHandling_v1.md), [Vehicle Curves](Wardogs_VehicleCurves_v1.md), [All Vehicles Stats and Damage](../content/Wardogs_AllVehicles_Stats_Damage_v1.md).

## How to read a row

- Each row flattens the asset's `Properties` to `path=value`. Tags show as the tag name, object references as the referenced asset name, and curve key lists as `time->value` points. Null and empty values are dropped. A long row is cut with `(+N more values)`; the file under the Asset link has everything.
- Property names beginning `_aaab...` are obfuscated names the export could not resolve; they are shown as stored, with no meaning claimed.
- Files too large to list (tire-model lookup grids, interaction contexts, buildable stage tables) show only the top-level properties with their leaf-value counts.
- What an asset type is for (a variant assembles a platform, a weapon extension binds an item and ammo to a slot) is **inference** from the engine class name and the property names; the export stores no documentation.
- Left out on purpose: audio (`WDAudioData` files, `AEB_*` audio event behaviours, `CrosstalkAudioEvent`, `REVModelAsset` engine-sound models) and UI radial-wheel slot types. This page documents no audio or UI widget assets.
