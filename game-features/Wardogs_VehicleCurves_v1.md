# Wardogs: Vehicle Curves (every CRV_* curve under the vehicle folders)

*Source: every `CurveFloat` export named `CRV_*` under the vehicle folders of `data/Wardogs` (`Plugins/GameFeatures/Vehicles/*` and `Content/Vehicles`), and the vehicle assets that reference them. Every table below is generated by [`_tools/vehicle_curve_tables.py`](https://github.com/Kiyogitpy/wardogs-data-docs/blob/main/_tools/vehicle_curve_tables.py); do not edit it by hand.*

Each row lists the curve keys as `time -> value`. The export stores no axis labels or units, so what the input and output mean is read from the asset that references the curve (the slot name in brackets when the export gives a specific one, such as `TorqueCurve`). Where this page says what an axis is, that is **inference** from the slot name and the key ranges, not a recovered unit. Several vehicles share a curve file name in different folders (`CRV_Torque`, `CRV_ThrottleEngagement`, ...); the Folder column tells them apart.

Related pages: [Vehicle Handling](Wardogs_VehicleHandling_v1.md) (drivetrain, axles, suspension per variant), [Vehicle Damage Pipeline](../pipelines/Wardogs_VehicleDamagePipeline_v1.md) and [All Vehicles Stats and Damage](../content/Wardogs_AllVehicles_Stats_Damage_v1.md).
